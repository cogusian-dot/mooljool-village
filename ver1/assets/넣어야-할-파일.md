# 넣어야 할 에셋 파일 목록

원본 아티팩트에서는 이 파일들이 HTML 안에 데이터로 묶여 있어서 꺼낼 수 없었어요.
원본 파일을 **아래 이름 그대로** 각 폴더에 넣으면 게임이 자동으로 찾아 써요. 파일이 없어도 게임은 실행되지만 그 자리가 비어 보여요.

## models/ — 가장 중요
| 파일 | 내용 | 없으면 |
|---|---|---|
| `ttami.glb` | 땀땀이 3D 모델 (Inventor CAD에서 GLB로 내보낸 것) | 단순한 원통 모양 임시 모형이 대신 나와요 |

부품 이름에 `상단부` `하단부` `가림막` `눈` `물방울` `센서` `서보` `분배`가 들어가야 색과 물방울 움직임이 제대로 적용돼요. 원래 아티팩트에 쓰던 모델 파일이면 그대로 맞아요.

## video/ — 영상 (파일당 25MB 이하)
| 파일 | 언제 나오나 |
|---|---|
| `package.mp4` | 식물 완성 후 "땀땀이 알아보기"를 누르면 나오는 패키지 영상 |
| `app.mp4` | "물줄때 앱 알아보기"를 누르면 나오는 앱 영상 |
| `mechanism.mp4` | 설명 페이지의 작동 원리 영상 |
| `ad.mp4` | 설명 페이지의 광고 영상 |

webp 대신 png/jpg밖에 없으면 개발 담당자에게 변환을 부탁하세요(이름과 확장자가 달라지면 게임이 못 찾아요).
