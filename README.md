# 물줄때 마을 · 땀땀이와 씨앗 이야기

경기과학기술대학교 디자인공학과 4CUS 팀의 MooljoolDay(물줄때) 프로젝트 3D 웹 게임입니다.
(2026 GTEC 디자인공학 페어 전시용) 이 폴더를 통째로 GitHub에 올리면 누구나 인터넷 주소로 게임을 할 수 있어요.

> 개발을 몰라도 괜찮아요. 이 문서는 GitHub를 한 번도 써 본 적 없는 분을 위해 썼어요.

## 1. 폴더 구조 — 언제 건드리나?

| 폴더 / 파일 | 무엇이 들어 있나 | 언제 건드리나 |
|---|---|---|
| `js/data.js` | 캐릭터 이름·인사말, 씨앗 이름·설명·물 주기 정보 | **가장 자주.** 캐릭터·씨앗 글자를 고치고 싶을 때 |
| `assets/img/` | 그림, 사진 | 이미지를 바꾸고 싶을 때 |
| `assets/video/` | 영상 | 영상을 바꾸고 싶을 때 |
| `assets/slides/` | 정보 페이지 슬라이드 이미지 | 슬라이드를 바꾸고 싶을 때 |
| `assets/chars/` | 캐릭터 그림 | 캐릭터 모습을 바꾸고 싶을 때 |
| `assets/models/` | 3D 모델 파일 | 거의 안 건드림 |
| `assets/fonts/` | 글꼴 파일 | 거의 안 건드림 |
| `index.html` | 게임의 첫 화면(뼈대) | 거의 안 건드림 |
| `css/` | 색·크기·배치 같은 모양 | 디자인을 손볼 때만 (개발자와 상의) |
| `js/` (data.js 빼고) | 게임이 움직이는 프로그램 | 건드리지 마세요 (개발자 영역) |
| `lib/three/` | 3D 그래픽 도구(Three.js) | 절대 건드리지 마세요 |
| `.nojekyll` | 빈 파일. GitHub가 파일을 멋대로 바꾸지 않게 해 줌 | 지우지 마세요 |
| `tests/` | 자동 점검용 (개발자용) | 신경 쓰지 않아도 돼요 |
| `README.md` | 지금 읽는 이 설명서 | 설명을 보탤 때 |

## 2. 처음 배포하기 (인터넷에 올리기)

"배포"는 내 파일을 인터넷 주소로 볼 수 있게 올리는 것을 말해요. 약 15분 걸려요.

### ① GitHub 가입
1. https://github.com 에 들어가 **Sign up** 을 눌러 가입합니다.
2. 이때 정하는 **아이디(Username)** 가 나중에 게임 주소에 들어가요. 영어 소문자로 짧게 정하면 좋아요.

### ② 새 저장소 만들기
**저장소(Repository)** = 파일을 보관하는 GitHub 위의 폴더 하나라고 생각하면 돼요.

1. 오른쪽 위 **+** 버튼 → **New repository**
2. **Repository name**: 예) `mooljool-village` (영어·숫자·하이픈만, 이 이름이 주소에 들어가요)
3. **Public** 을 선택합니다. (Private 이면 무료로 사이트를 열 수 없어요)
4. 아래의 다른 체크박스(README 추가 등)는 **건드리지 말고** → **Create repository**

### ③ 파일 올리기
1. 새 저장소 화면에서 **uploading an existing file** 이라는 파란 글씨를 누릅니다.
2. 내 컴퓨터에서 이 폴더를 열고, **폴더 자체가 아니라 폴더 안의 내용물 전부**를 선택해서 브라우저 창으로 끌어다 놓습니다.
   - 맞는 예: `index.html`, `css`, `js`, `assets`, `lib`, ... 를 모두 선택해서 끌기
   - 틀린 예: `mooljool-village` 폴더 하나를 끌기 → 주소가 꼬여서 화면이 안 떠요
3. **숨김 파일 `.nojekyll` 주의!** 이름이 점(.)으로 시작하는 파일은 평소에 안 보여요.
   - **Mac**: Finder 에서 `Cmd + Shift + .` (마침표) 를 누르면 숨김 파일이 보여요. 다시 누르면 숨겨져요.
   - **Windows**: 파일 탐색기 위쪽 **보기** → **표시** → **숨긴 항목** 체크
   - 보이게 한 다음, 다른 파일과 함께 선택해서 올리세요.
4. 업로드가 다 끝날 때까지 기다립니다. (파일이 많으면 몇 분 걸려요)

### ④ 저장(커밋)하기
**커밋(Commit)** = "이 상태로 저장할게요" 하고 확정하는 버튼이에요.

1. 페이지 아래로 내려가 초록색 **Commit changes** 버튼을 누릅니다.
2. 메시지 칸은 비워 둬도 되고, "처음 올림" 처럼 적어도 돼요.

### ⑤ 사이트 켜기 (GitHub Pages)
1. 저장소 위쪽 메뉴에서 **Settings** (톱니바퀴)
2. 왼쪽 메뉴에서 **Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` 선택, 옆 칸은 `/ (root)` → **Save**

### ⑥ 확인
1~3분 기다린 뒤 아래 주소로 들어가 보세요.

```
https://<아이디>.github.io/<저장소이름>/
```

예) 아이디가 `fourcus`, 저장소가 `mooljool-village` 라면 → `https://fourcus.github.io/mooljool-village/`

Settings > Pages 화면 위쪽에도 "Your site is live at ..." 하고 주소가 나와요.

## 3. 자주 하는 수정

수정은 전부 **GitHub 웹사이트에서** 할 수 있어요. 고치고 커밋하면 1~3분 뒤 사이트에 반영돼요.

### (a) 캐릭터·씨앗 글자 고치기 → `js/data.js`

1. 저장소에서 `js` 폴더 → `data.js` 클릭
2. 오른쪽 위 **연필 아이콘(Edit this file)** 클릭
3. 바꾸고 싶은 글자를 찾아 고칩니다. (`Ctrl+F` / `Cmd+F` 로 찾기 가능)
4. 오른쪽 위 **Commit changes...** → 다시 **Commit changes**

예를 들어 캐릭터 한 줄은 이렇게 생겼어요.

```
{ id: 'bukbuk', name: '북북이', img: 'c04', ..., line: '책 읽는 게 세상에서 제일 좋아.' },
```

**규칙 3줄 요약** (이것만 지키면 돼요)
1. **작은따옴표 `'...'` 안의 글자만** 고치세요. 따옴표 자체는 지우지 마세요.
2. 글 안에 작은따옴표 `'` 를 쓰고 싶으면 앞에 역슬래시를 붙여 `\'` 로 쓰세요. (큰따옴표·물음표·느낌표는 그냥 써도 돼요)
3. `id:` `img:` `seed:` 처럼 **영어로 된 값은 건드리지 마세요.** 게임이 그 이름으로 그림과 씨앗을 찾아요. 줄 끝의 쉼표 `,` 와 괄호 `{ }` `[ ]` 도 그대로 두세요.

**틀렸을 때 증상**: 사이트에 들어가면 "마을을 빚는 중…" 로딩 화면에서 넘어가지 않아요.

**되돌리는 방법 (History)**
1. `data.js` 파일 화면에서 오른쪽 위 **History** (시계 아이콘) 클릭
2. 잘 되던 때의 기록을 눌러 그때 내용을 확인합니다.
3. 가장 쉬운 방법: 그 기록에서 **`...` → View file → Raw** 로 원래 내용을 전부 복사해서, 다시 연필 아이콘으로 열고 통째로 붙여 넣은 뒤 커밋하세요.

땀땀이 대사나 "땀땀이 알아보기" 페이지 글은 `js/game.js`, `index.html` 안에 있어요. 고치고 싶으면 개발 담당자에게 부탁하는 게 안전해요.

### (b) 이미지 바꾸기 → **같은 파일 이름으로 덮어 올리기**

1. 바꿀 이미지의 **파일 이름과 확장자**(예: `seed01.png`)를 확인해 둡니다.
2. 새 이미지 파일 이름을 **똑같이** 바꿉니다. (대소문자, `.png`/`.jpg` 까지 똑같이)
3. 그 이미지가 있는 폴더(예: `assets/img`)로 들어가 오른쪽 위 **Add file → Upload files**
4. 끌어다 놓고 **Commit changes** → 같은 이름이라 자동으로 덮어써져요.

이름이 다르면 게임이 새 이미지를 찾지 못해요. 이미지는 가능하면 1MB 이하가 좋아요.

### (c) 영상 바꾸기 → 25MB 이하로 줄이기

웹에서는 파일 하나당 **25MB** 까지만 올릴 수 있어요. 영상이 크면 줄여야 해요.

1. 무료 앱 **HandBrake** (https://handbrake.fr) 를 설치합니다.
2. 영상을 열고, 오른쪽 **Preset** 에서 **General → Fast 720p30** 선택
3. 그래도 크면 **Video** 탭에서 **Constant Quality** 숫자를 올리거나(예: 22 → 26), 영상 길이를 줄이세요.
4. 형식은 **MP4**, 파일 이름은 원래 영상과 **똑같이** 해서 `assets/video/` 에 (b)처럼 덮어 올리세요.

### (d) 바꾼 게 안 보일 때

1. 커밋 후 **1~3분** 기다립니다. (저장소 위쪽 **Actions** 탭에서 초록 체크가 뜨면 반영 완료)
2. 브라우저가 옛날 파일을 기억하고 있을 수 있어요. **강력 새로고침** 하세요.
   - Windows: `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`
3. 휴대폰은 시크릿(비공개) 창으로 열어 보면 확실해요.

## 4. 제한 사항

| 항목 | 제한 |
|---|---|
| 웹에서 올리는 파일 하나 | 25MB 까지 |
| 사이트 전체 크기 | 1GB 권장 한도 |
| 용도 | GitHub Pages 는 **사업·판매 목적 사이트에 쓸 수 없어요** (전시·포트폴리오는 괜찮아요) |

### 나중에 Vercel 로 옮기고 싶다면

Vercel 은 사이트를 올려 주는 다른 서비스예요. GitHub 저장소를 그대로 연결할 수 있어요.

1. https://vercel.com 에서 **Continue with GitHub** 로 가입합니다.
2. **Add New → Project** → **Import Git Repository** 에서 이 저장소를 고르고 **Import**
3. **Framework Preset** 은 `Other`, Build 관련 설정(Build Command, Output Directory)은 **모두 비워 두고** → **Deploy**

이후 GitHub 에서 커밋할 때마다 Vercel 사이트도 자동으로 바뀌어요.
주의: Vercel 무료 요금제(**Hobby**)도 **비상업용만** 쓸 수 있어요.

## 5. 내 컴퓨터에서 미리 보기 (선택)

올리기 전에 내 컴퓨터에서 먼저 확인하고 싶을 때 쓰는 방법이에요. 안 해도 배포에는 문제없어요.

`index.html` 을 더블클릭해서 열면 브라우저 보안 때문에 3D 모델 파일(`ttami.glb`)을 불러오지 못해요. 그러면 땀땀이가 단순한 임시 모형으로 보여요. 제대로 보려면 작은 "임시 서버"를 켜야 해요.

1. 터미널을 엽니다. (Mac: 응용 프로그램 → 유틸리티 → 터미널 / Windows: 시작 메뉴에서 "PowerShell")
2. 이 폴더로 이동합니다. `cd ` (cd 뒤에 한 칸 띄우고) 입력 후 폴더를 터미널 창에 끌어다 놓고 Enter
3. 아래 명령을 입력하고 Enter

```
python3 -m http.server 8000
```

(Windows 에서 안 되면 `python -m http.server 8000`. 파이썬이 없으면 https://python.org 에서 설치)

4. 브라우저에서 http://localhost:8000 접속
5. 다 봤으면 터미널에서 `Ctrl + C` 로 끕니다.

## 6. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 주소에 들어가면 **404** 가 뜸 | Pages 를 아직 안 켰거나, 반영 전이거나, 주소가 틀림 | Settings > Pages 확인 → 1~3분 대기 → 주소 끝의 저장소 이름 철자 확인 |
| 로딩 화면에서 멈춤 | `data.js` 따옴표·쉼표 실수 | History 로 직전 커밋 확인, 3-(a) 방법으로 되돌리기 |
| 404 인데 저장소에 `index.html` 이 안 보임 | 폴더째 올려서 한 단계 안쪽에 들어감 | 내용물만 다시 올리기 (저장소 첫 화면에 `index.html` 이 바로 보여야 함) |
| 그림·영상만 안 나옴 | 파일 이름(대소문자·확장자)이 원래와 다름 | 원래 이름과 똑같이 바꿔서 다시 올리기 |
| 영상 업로드가 안 됨 | 25MB 넘음 | 3-(c) HandBrake 로 줄이기 |
| 고쳤는데 그대로임 | 반영 대기 중이거나 브라우저 기억(캐시) | 1~3분 대기 후 강력 새로고침 (`Ctrl/Cmd + Shift + R`) |
| 땀땀이가 밋밋한 원통 모양 | `assets/models/ttami.glb` 파일이 없거나, 더블클릭으로 열었음 | 모델 파일을 넣고, 5번처럼 임시 서버로 열기 (인터넷에 올린 사이트는 정상) |

그래도 해결이 안 되면, 화면 캡처와 함께 "무엇을 고친 뒤 이렇게 됐는지"를 개발 담당자에게 알려 주세요.
